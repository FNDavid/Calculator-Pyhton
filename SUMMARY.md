# Resumen del Proyecto / Project Summary

## Calculadora Python con Tkinter

Este repositorio contiene una calculadora completa implementada en Python utilizando la biblioteca Tkinter para la interfaz gráfica.

### Archivos Principales / Main Files

1. **calculator.py** - Aplicación principal de la calculadora
2. **test_calculator.py** - Suite completa de pruebas unitarias
3. **example_usage.py** - Ejemplos de uso y demostraciones
4. **README.md** - Documentación principal
5. **FEATURES.md** - Descripción detallada de características

### Estadísticas del Proyecto / Project Statistics

- **Líneas de código**: ~180 líneas (calculator.py)
- **Pruebas unitarias**: 11 tests (100% de cobertura en lógica)
- **Operaciones soportadas**: 5 (suma, resta, multiplicación, división, módulo)
- **Tamaño de ventana**: 400x600 píxeles

### Tecnologías Utilizadas / Technologies Used

- Python 3.12+
- Tkinter 8.6
- unittest (para testing)

### Características Destacadas / Key Features

✅ Interfaz gráfica moderna y responsive
✅ Manejo robusto de errores
✅ Código bien documentado (español e inglés)
✅ Tests unitarios completos
✅ Diseño intuitivo y fácil de usar
✅ Colores diferenciados por tipo de botón

### Cómo Ejecutar / How to Run

```bash
# Instalar tkinter (si es necesario)
sudo apt-get install python3-tk  # Ubuntu/Debian

# Ejecutar la calculadora
python3 calculator.py

# Ejecutar las pruebas
python3 -m unittest test_calculator.py -v

# Ver ejemplos
python3 example_usage.py
```
