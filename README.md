# Calculator-Python
Una calculadora simple escrita en Python con Tkinter / A simple calculator written in Python with Tkinter

## Descripción / Description

**Español:** Esta es una calculadora gráfica simple creada con Python utilizando la biblioteca Tkinter. Incluye operaciones básicas como suma, resta, multiplicación, división y módulo.

**English:** This is a simple graphical calculator created with Python using the Tkinter library. It includes basic operations such as addition, subtraction, multiplication, division, and modulo.

## Características / Features

- ✅ Interfaz gráfica moderna y fácil de usar
- ✅ Operaciones básicas: +, -, *, /, %
- ✅ Función de borrar (C) y retroceso (←)
- ✅ Manejo de errores (división por cero, expresiones inválidas)
- ✅ Diseño responsive con colores diferenciados

## Requisitos / Requirements

- Python 3.x
- Tkinter (incluido con Python en la mayoría de las instalaciones)

### Instalación de Tkinter / Installing Tkinter

**Ubuntu/Debian:**
```bash
sudo apt-get install python3-tk
```

**macOS:**
Tkinter viene incluido con Python en macOS.

**Windows:**
Tkinter viene incluido con Python en Windows.

## Uso / Usage

**Español:** Para ejecutar la calculadora, simplemente ejecuta el archivo Python:

```bash
python3 calculator.py
```

**English:** To run the calculator, simply execute the Python file:

```bash
python3 calculator.py
```

## Pruebas / Tests

**Español:** Para ejecutar las pruebas unitarias:

```bash
python3 -m unittest test_calculator.py -v
```

**English:** To run the unit tests:

```bash
python3 -m unittest test_calculator.py -v
```

## Funcionalidades / Functionality

### Botones / Buttons

- **0-9**: Números / Numbers
- **.**: Punto decimal / Decimal point
- **+, -, *, /**: Operaciones básicas / Basic operations
- **%**: Módulo / Modulo
- **=**: Calcular resultado / Calculate result
- **C**: Limpiar todo / Clear all
- **←**: Borrar último carácter / Backspace
